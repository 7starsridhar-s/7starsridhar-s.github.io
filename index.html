Selected work

Thozhil (தொழில்) — textile business management platform

React 18 · Vite · Firebase · npm workspaces · PWA · Tamil / English i18n

Small textile units in and around Hosur still run on paper — job cards, labour wages, customer orders. Thozhil is my attempt at replacing that, and the interesting constraint is that three completely different people use it: the owner, the labourer on the floor, and the customer placing an order. One app trying to serve all three would be a permissions maze, so I split it into three.

  • Thozhil BossOwner — orders, wages, reporting
  • Thozhil WorkLabour — job cards, work entry
  • Thozhil ShopCustomer — orders, status
  • Refactored a single-bundle app into an npm workspaces monorepo — each of the three apps is a standalone Vite + React 18 build with its own entry, router and role lock, so a labourer's bundle never ships owner-only code.
  • All three sit on one shared package: Firebase Auth and Firestore access, auth hooks, role-based route guards, a 12-theme design system and a 171-key Tamil/English i18n layer. A shared rule now changes in one place instead of three.
  • Tamil is a first-class language, not an afterthought — the shop floor reads Tamil, the reports go out in English, and the same key set drives both.
  • Shipped as an installable offline-capable PWA with a full brand and SVG asset system, because connectivity inside a textile unit is unreliable and work entry can't wait for a network.
